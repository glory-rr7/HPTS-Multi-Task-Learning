# label_demo - 手写字与打印字智能分割标注工具

## 概述

`label_demo` 目录包含了用于手写字与打印字智能分割技术的标注工具集。该工具集提供了完整的标注流程，从原始图像处理到最终的数据集生成。

## 目录结构

```
label_demo/
├── script/                      # 标注脚本工具
│   ├── batch_mask.py           # 批量掩码生成
│   ├── batch_rebuld.py         # 批量重建处理
│   ├── init_dir.py             # 目录初始化
│   ├── interactive_binarize.py # 交互式二值化
│   ├── single_binarize.py     # 单图二值化
│   └── tools/                  # 工具函数
│       ├── dir_setting.py      # 目录设置
│       └── utils.py            # 通用工具
├── demo/                        # 示例数据
│   ├── images/                 # 原始图像
│   ├── mask/                   # 掩码图像
│   ├── erased/                 # 擦除后图像
│   ├── erased_binary/          # 擦除后二值化图像
│   ├── images_binary/          # 原始二值化图像
│   ├── overlap_mask/           # 重叠掩码
│   └── rebuild/               # 重建图像
└── 手写字与打印字智能分割技术标注方法.pdf  # 详细标注文档
```

## 主要功能

### 1. **图像预处理**
- 原始图像加载和处理
- 图像二值化处理
- 交互式图像调整

### 2. **标注工具**
- 掩码生成和编辑
- 手写字与打印字区域分割
- 重叠区域处理

### 3. **批量处理**
- 批量掩码生成
- 批量图像重建
- 目录结构自动初始化

### 4. **数据输出**
- 擦除后图像生成
- 重建图像输出
- 多格式数据保存

## 使用流程

1. **初始化**: 使用 `init_dir.py` 创建标注目录结构
2. **预处理**: 使用二值化脚本处理原始图像
3. **标注**: 使用交互式工具进行区域标注
4. **批量处理**: 使用批量脚本处理大量数据
5. **输出**: 生成最终的训练数据集

## 详细文档

详细的标注方法和操作步骤请参考：
**`手写字与打印字智能分割技术标注方法.pdf`**

该PDF文档包含了完整的标注流程、操作指南和最佳实践。

## 注意事项

- 确保图像质量良好，便于后续处理
- 标注时注意保持手写字和打印字的边界清晰
- 定期备份标注数据，避免数据丢失

## 依赖要求

- Python 3.6+
- OpenCV
- PIL/Pillow
- NumPy
- Matplotlib (用于交互式显示)
